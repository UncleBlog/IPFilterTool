# IP 地址筛选工具 v1.1.1 使用说明

作者：Uncledavid

## 使用方法

1. 双击 `IP筛选工具_v1.1.1.exe` 运行。
2. 在“批量输入待筛选 IP”框中输入 IP，可每行一个，也可用空格、逗号或分号分隔。
3. 点击“开始筛选”。
4. 历史记录中不存在的 IP 会显示在右侧“本次新增 IP”，并自动加入左侧历史记录。
5. 历史记录中已存在的 IP 会跳过，不进入“本次新增 IP”。

## 历史 IP 操作

- 勾选单个或多个 IP 后，可复制或删除勾选内容。
- 左侧切换按钮可在“全选当前”和“取消全选”之间切换。
- 右击未勾选的 IP，可直接复制或删除该 IP。
- 右击已勾选的 IP，可复制或删除全部已勾选 IP。
- 使用空格键可切换当前选中行的勾选状态，按 Delete 键可删除已勾选 IP。

## 本次新增 IP 操作

- 与历史 IP 使用相同的勾选、多选、全选切换、复制、删除和右键菜单操作。
- 左上方“全选当前 / 取消全选”用于勾选或取消当前全部新增 IP。
- “复制勾选新增 IP”复制一个或多个已勾选 IP。
- “删除勾选新增 IP”删除一个或多个已勾选 IP。
- 右击未勾选的新增 IP，可直接复制或删除该 IP。
- 删除新增 IP 时，会同步从历史记录中移除，避免该 IP 之后被判定为“历史已存在”。
- 本次新增区域不提供查询功能。

## 历史 IP 查询

- 输入完整 IP 或部分 IP 即可筛选。
- 查询框支持鼠标右键菜单。
- 右击查询框选择“粘贴 IP”，会从剪贴板读取并自动填入第一个 IP 地址。
- 也支持复制、全选和清空查询框内容。

## 其他功能

- 支持 IPv4 和 IPv6。
- 自动去重并提示无效输入。
- 历史记录持久保存，关闭程序后不会丢失。
- 可导出历史记录为 CSV。

## 数据保存位置

```text
%APPDATA%\IP筛选工具\history.json
```
